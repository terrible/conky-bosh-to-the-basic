# Rendimiento

Referencias históricas informadas: BASE-01 5,8462 %, OPT-01 5,7609 %, OPT-02 9,9697 %. OPT-02 fue rechazada. El benchmark sintético verifica cinco consultas NVIDIA de OPT-01 frente a una consulta consolidada y mide CPU de procesos hijos. No representa el consumo total ni equivale a las referencias históricas.

## Procedimiento real

`tools/benchmark-real.sh [--smoke-test] OPT01_THEME CANDIDATE_THEME OUTPUT.csv` es el runner reproducible. Verifica las huellas de OPT-01, copia ambos temas a un laboratorio privado, normaliza solo esas copias para X11 y usa Xvfb con cookie Xauthority privada. Lanza cada Conky en primer plano dentro de un scope de usuario propio y exige una ventana mapeada, visible, de geometría estable. El smoke-test mide 3 s de calentamiento y 5 s; no habilita el benchmark completo si falla. El modo completo alterna tres muestras por variante, con 30 s de calentamiento y 60 s de medición en la misma instancia. El CSV registra tiempos, CPU del cgroup, worker, wrapper NVIDIA, RSS, consultas y dimensiones; el JSON reporta mediana y desviación estándar. No detiene Conky de producción.

Las cifras físicas no deben compararse directamente con BASE-01/OPT-01 históricos: cambian protocolo, X server, instrumentación y carga del anfitrión. QA-19 repitió el protocolo en 2026-11-27 tras restaurar la barra Intel omitida. OPT-01 registró 10,147 %, 10,041 % y 10,061 % CPU de un núcleo (mediana 10,061 %, DE 0,056); el candidato registró 4,167 %, 4,240 % y 4,354 % (mediana 4,240 %, DE 0,094). Consultas NVIDIA: 48 por muestra OPT-01 y 12 por muestra candidata; 0 fallidas. Geometría estable: 283×893 en las seis muestras. La CPU agregada cayó aproximadamente 57,85 % entre medianas. Es un resultado pareado de este host y protocolo, no una garantía para otros equipos.

La investigación QA-19 localizó el delta histórico de 17 px: el lector Intel OPT-01 emite una fila de porcentaje alineada a la derecha y, con sensor válido, una segunda fila `${execbar 4,259 ...}`. El candidato omitía esa barra. La fixture visual QA-18 sustituyó el comando por un `echo` de una fila, ocultando el caso. Se restauró una barra equivalente con Lua (sin proceso hijo) y la alineación original. En la comparación sintética corregida ambas ventanas midieron 283×927 con ImageMagick AE=0; en smoke y benchmark físico ambas midieron 283×893. Esta corrección recupera la geometría y contenido, por lo que el benchmark QA-19 reemplaza el resultado QA-18.

RSS pico de Conky (mediana): 209,666,048 B OPT-01 y 103,124,992 B candidato. El worker midió ~23 MB para ambos. RSS de procesos con páginas compartidas puede contar páginas repetidas; no se interpreta como memoria física exclusiva ni se suman worker y panel como si no compartieran bibliotecas. La memoria/coste del wrapper NVIDIA se contabiliza por separado dentro de cgroup; sus medianas fueron 0,03 s y 0,01 s por ventana de 60 s.

El campo `cgroup_cpu_seconds` es la métrica agregada autoritativa e incluye Conky y todos sus hijos. `panel_cpu_seconds` en CSV es cgroup menos el worker de QA; por ello incluye los procesos auxiliares y el wrapper `nvidia-smi`. `nvidia_wrapper_cpu_seconds` mide el tiempo propio del wrapper Python y se solapa con ese agregado: **no sumar esos campos**. El ejecutable `nvidia-smi` hijo permanece dentro del agregado y no se atribuye individualmente en esta versión del runner. La comparación de CPU entre variantes usa el cgroup total, que sí contiene todos los costes.

## QA-21.3 — parser NVIDIA corregido

El defecto se detectó en Plasma real: `nvidia-smi` emitía temperatura decimal (por ejemplo `34.22`), mientras el parser entero convertía solo ese campo en no disponible. La corrección parsea temperatura por separado como decimal finito en rango 0–150; VRAM y utilización conservan su validación entera estricta. Se conserva el formato OPT-01: se comparan umbrales con el dato original y luego se redondea para mostrar (`34.22` → `34°C`; `74.9` se muestra `75°C` sin alerta; 75 inicia advertencia y 85 alerta). La consulta continúa siendo una por snapshot.

Benchmark físico QA-21.3, EndeavourOS, i5-3330 y GTX 1650: tres muestras alternadas por variante, 30 s de calentamiento y 60 s medidos en scopes v2 independientes. CPU equivalente a un núcleo: OPT-01 9.807/9.845/9.880 % (mediana **9.845 %**, DE **0.036510**); candidato 4.310/4.392/4.161 % (mediana **4.310 %**, DE **0.117108**). Reducción entre medianas **56.22 %** en esta ejecución. NVIDIA: 48 frente a 12 consultas/minuto, cero fallidas. Geometría en las seis muestras: 283×893. RSS mediana del panel: 207,937,536 B / 103,411,712 B; worker aproximadamente 23 MB. El RSS puede contar páginas compartidas, por lo que no equivale a memoria física exclusiva. El wrapper tuvo CPU propia mediana 0.02 s / 0.00 s por ventana de 60 s; ese campo se solapa con el total del cgroup y no se suma.

Evidencia local, no incluida en el repositorio: CSV `/tmp/bosh-qa21-benchmark.gDAsUAt2/benchmark.csv`, resumen `/tmp/bosh-qa21-benchmark.gDAsUAt2/benchmark.csv.json`, logs `/tmp/bosh-qa21-benchmark.gDAsUAt2/benchmark.csv.logs/`. El smoke pasó con geometría 283×893 y consultas 4/1 sin fallos: `/tmp/bosh-qa21-smoke.kK53NdES/smoke.csv`. Esta ejecución es una medición nueva; QA-19 permanece como histórico y no se sustituye por comparación entre protocolos distintos.

La inspección visual de escritorio QA-21.4 reportada por el mantenedor confirmó las métricas NVIDIA visibles después de esta medición. No se repitió el benchmark para el cierre documental: QA-21.4 no modificó el código.
