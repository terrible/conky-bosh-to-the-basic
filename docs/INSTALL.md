# Instalación

Instala manualmente Conky compatible y Noto Sans desde la distribución. Referencias habituales: Arch/EndeavourOS, paquetes `conky` y `noto-fonts`; Fedora, `conky` y `google-noto-sans-fonts`.

Ejecuta `./install.sh --dry-run`, luego `./install.sh` y `./install.sh --verify`. Se instala solo dentro de HOME, migra el autostart Bosh reconocido y conserva predecesores en estado XDG privado. El servicio Intel es opcional y requiere preparación administrativa separada.
